# Rawsam printer

تطبيق iOS لطباعة ستنسل الوشم على طابعة MHT-P19 (Hercules) عبر البلوتوث، لـ روسم تاتو.

## الأجزاء
- `App/` كود التطبيق (SwiftUI).
- `branding/logo.png` اللوكو، ومنه تتولد الأيقونة وقت البناء (`tools/make_art.py`).
- `ci/build.sh` خطوات البناء. كل رفع على `main` يبني `RawsamPrinter-vX.Y.Z.ipa` بقسم Releases.

## المكتبة السحابية
الصور والأقسام والبانر محفوظة بفرع `library` بنفس المستودع:
- `config.json` الأقسام، البانر، سرعة البانر، وبصمة كلمة سر المدير.
- `files/` الصور (أسماء إنگليزية عشوائية).

كل المستخدمين يقرون منها مجاناً. المدير يعدّل من داخل التطبيق (الإعدادات ← دخول المدير)،
والرفع يحتاج رمز GitHub ينحط مرة وحدة بتلفون المدير. **لازم يبقى المستودع Public** حتى يگدر التطبيق يقرا المكتبة.

## الطباعة
أوامر الطابعة مبنية على توثيق MHT-500 من
[meabefir/mht500-stencil-link](https://github.com/meabefir/mht500-stencil-link)، وتجربت على MHT-P19 واشتغلت.
